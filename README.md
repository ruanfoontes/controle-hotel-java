# 🏨 Sistema de Gerenciamento de Hotel (Java)

Este é um projeto desenvolvido para praticar **Java puro**, utilizando **programação orientada a objetos (POO)** e operações CRUD diretamente no **terminal**.  
O sistema permite gerenciar hotéis e realizar operações básicas de cadastro, listagem, atualização e remoção.

---

## 🚀 Funcionalidades

### ✔️ **CRUD de Hotéis**
- Cadastrar novo hotel  
- Listar hotéis cadastrados  
- Buscar hotel pelo ID  
- Atualizar informações  
- Remover hotel  

### ✔️ **Interface no Terminal**
- Menu organizado e limpo  
- Navegação intuitiva  
- Pausa automática após cada ação  

### ✔️ **Estrutura do Projeto**
- Uso de classes e objetos  
- Encapsulamento com getters e setters  
- Classe `Hotel` com atributos e `toString()`  
- Uso de `ArrayList` para armazenar dados na memória  

---

## 🛠️ Tecnologias Utilizadas

- **Java 17+**  
- **Programação Orientada a Objetos (POO)**  
- **Scanner** para entrada de dados  
- **ArrayList** para armazenamento temporário
